# Spec 12: Competitive Analysis

## Goal
Show market awareness — Fortress didn't design in a vacuum. Compare against real categories of existing tools landlords actually use.

## Scope
In:
- A comparison table/grid in Figma: Fortress vs. 2-3 real competitor categories (e.g. Landlord Studio, Stessa, a plain spreadsheet) across a handful of dimensions relevant to the target user (small NZ landlord, 2-10 rooms).
- Screenshot it, add a "Where Fortress fits" section to the case study.

Out:
- Deep feature-by-feature audits of real competitor products (this is a portfolio piece, not a market research report — keep dimensions honest but high-level).

## Approach
1. Pick 3 comparison dimensions that matter to the persona (Ben): built for portfolio size, per-room rent tracking, freedom/net-worth framing.
2. Build a simple comparison grid/table in Figma using design tokens.
3. Screenshot, add to case study.

## Done when
- Comparison artifact built in Figma, screenshot added to case study with a short framing paragraph.
