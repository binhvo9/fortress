# Spec 13: Logo / App Icon Exploration

## Goal
Show brand-mark thinking, not just a color+type system — Fortress currently has no icon/logomark of its own.

## Scope
In:
- 4 app-icon concept directions built as simple geometric marks (shield, house+growth, coin stack, keyhole) in iOS app-icon squares, using brand tokens.
- Mark one as the selected direction with a visible "Selected" treatment.
- Add a short "Brand Mark" section to the case study with the exploration + rationale for the pick.

Out:
- Full icon set / favicon variants across sizes.
- Wordmark lockup exploration (color system + Fraunces wordmark already covers this).

## Approach
1. Build 4 icon concepts as vector shapes on a dedicated Figma page, using boolean operations for simple glyphs — no external icon libraries.
2. Mark the selected one.
3. Screenshot, add to case study with rationale.

## Done when
- 4 icon concepts + 1 marked selection visible in one screenshot, case study updated.
