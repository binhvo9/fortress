# Specs

One file per feature/task, e.g. `01-figma-mcp-probe.md`, `02-design-system.md`. Claude works one spec at a time — pick from `CURRENT-FEATURES.md` backlog, write the spec here, execute it, mark it done, move it into the history section.

Each spec should cover: goal, scope (in/out), approach, done-when.
