# Spec 11: Persona Card

## Goal
Add a proper persona artifact (Goals/Pain Points/Motivations/Behavior quadrant, matching the convention seen in the Donor Hub reference case study) — currently Fortress only has a prose "why I built this" paragraph, no visual research artifact.

## Scope
In:
- Build a "Persona" page in the Figma file: persona identity block (avatar-as-initials, name, age, role, location) + quote + 4-quadrant Goals/Pain Points/Motivations/Behavior, styled with Fortress design tokens.
- Persona: a representative landlord archetype (not a real person, no stock photography — initials avatar in brand colors), distinct from the app's own placeholder tenant names already used.
- Export/screenshot it and add a "Meet the User" section to the case study artifact, replacing/supplementing the current prose-only "spark" section.

Out:
- Multiple personas (one primary persona is enough for this scope).
- Empathy map (separate spec).

## Approach
1. Design persona content (name, quote, goals/pain/motivation/behavior) — grounded in the same problem space as the existing IA/problem statement.
2. Build in Figma using design tokens (colors, type, radius) — new page.
3. Screenshot, download, add to case study as a new section.

## Done when
- Persona page exists in Figma, screenshot captured, case study updated with a "Meet the User" section.
