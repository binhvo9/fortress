# Spec 03: Information Architecture / Site Map

## Goal
Lock the screen list and hierarchy for Fortress before designing any screen, so screens 04+ build against an agreed structure instead of ad-hoc.

## Scope
In:
- Define the full screen list grounded in the product concept (property/rental management + wealth tracking).
- Draw a simple hierarchical site map (boxes + connectors) on its own page in the Figma file.

Out:
- Actual screen UI (later specs).
- Interaction/prototype wiring (later spec).

## Approach
1. Draft the IA in text first (screen list + hierarchy), log it in `design-log.md`.
2. Build a "Site Map" page in Figma: one box per screen (using Card/Label styling from the design system where sensible), connected top-down by simple lines.
3. Validate with `get_metadata` + screenshot.

## Done when
- IA documented in `design-log.md`.
- "Site Map" page exists in Figma with all screens and hierarchy visible in one screenshot.
