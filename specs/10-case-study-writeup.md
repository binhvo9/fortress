# Spec 10: Case Study Write-up

## Goal
Produce the final portfolio deliverable: a polished, Behance-style case study page telling the Fortress story, positioned for the "AI-Augmented Designer" narrative (per `PROJECT.md`).

## Scope
In:
- Published as an HTML Artifact (page the user can screenshot/export or link to reviewers directly) — not literally posted to Behance (no tooling for that), but structured the same way.
- Sections: hero/cover, overview (problem/role/tools), the personal motivation (light touch), design process (IA, design system), key screens with screenshots, the "Claude + Figma MCP workflow" section (curated highlights from `figma-mcp-capabilities.md`), reflection/closing.
- Use real screenshots captured from the Figma file (in this spec's scratch folder).

Out:
- Actually publishing to Behance/LinkedIn (user's call, outside this tool's scope).
- Video/animated prototype embed (static screenshots + a note that the Figma prototype is clickable).

## Approach
1. Load `artifact-design` skill before writing.
2. Draft content pulling from `design-log.md` (brand rationale, IA) and `figma-mcp-capabilities.md` (curated capability highlights, not the raw dev log).
3. Build as a single HTML artifact page, publish.

## Done when
- Case study artifact published, covering all sections above, using real captured screenshots.
